# Портфолио Дмитрия Фадеева

[Открыть сайт](https://nefrit333-cpu.github.io/dmitry-fadeev-portfolio/)

Статический сайт-портфолио Project Manager для digital-, B2B- и fashion-tech проектов. Сайт показывает опыт, кейсы, проектные артефакты, диплом Яндекс Практикума, публичные пет-проекты и форму связи.

## Текущая версия

Актуальный релиз: `v1.3.2`.

Что вошло в релиз:

- обновлена карточка Pixel Runner: вместо абстрактного превью используется dark game-визуал с оранжевым акцентом;
- W3Promo визуально выровнен с соседними кейсами: фон переведен в сине-черный тон, яркость выставлена на `brightness(1.25)`;
- CTA диплома сделана почти прозрачной, чтобы не спорить с основным визуальным ритмом;
- изображения проектных артефактов увеличены внутри карточек, чтобы убрать лишнюю пустоту;
- Figma-inspired минимализм: темный фон, крупная типографика, оранжевый акцент и чистая геометрия;
- компактный первый экран без портрета, с одним CTA «Посмотреть проекты»;
- единый header через burger-меню на desktop и mobile;
- блок «Обо мне» с новым editorial-портретом, метриками и встроенным дипломом Яндекс Практикума;
- блок «Ключевые кейсы» с фокусом на WID, W3Promo и Pixel Runner;
- визуальные карточки проектных артефактов с прямыми ссылками на Google Drive;
- отдельный мини-блок GitHub-проектов: Spine Flow, Pogoda Seychas, My First Site;
- контакты с Email, VK и скрытой формой, которая открывается только по кнопке;
- адаптивная верстка для современных мобильных экранов;
- диплом открывается внутри сайта как адаптивное изображение, без перехода в браузерный PDF-viewer.

Подробная история изменений: [CHANGELOG.md](CHANGELOG.md).

## Стек

- Astro;
- TypeScript;
- Astro Content Collections;
- CSS без UI-фреймворка;
- GitHub Pages;
- FormSubmit для отправки формы.

## Локальный запуск

```bash
npm.cmd install
npm.cmd run dev -- --host 127.0.0.1 --port 4323
```

Локальный адрес:

```text
http://127.0.0.1:4323/dmitry-fadeev-portfolio/
```

Сборка:

```bash
npm.cmd run build
```

Локальная проверка production-сборки:

```bash
npm.cmd run preview
```

## Структура проекта

```text
src/pages/index.astro          Главная страница
src/pages/privacy.astro        Политика конфиденциальности
src/pages/consent.astro        Согласие на обработку данных
src/styles/global.css          Визуальная система и адаптив
src/data/profile.ts            Основные данные профиля, ссылки, диплом и артефакты
src/content/experience/*.md    Опыт
src/content/projects/*.md      Кейсы
public/images/                 Портрет и визуалы кейсов
public/docs/                   PDF-документы, доступные с сайта
.github/workflows/deploy.yml   Публикация на GitHub Pages
```

## Контент

Опыт и кейсы хранятся в Astro Content Collections. Для нового кейса нужно заполнить `title`, `category`, `role`, `order`, `stack`, `links` и `outcomes`. Основные контакты, метрики, обучение, ссылки на артефакты и публичные проекты находятся в `src/data/profile.ts`.

## Публикация

Сайт настроен под репозиторий `dmitry-fadeev-portfolio` и базовый путь `/dmitry-fadeev-portfolio`.

После пуша в `master` GitHub Actions собирает Astro-проект и публикует его на GitHub Pages.

Публичный адрес:

```text
https://nefrit333-cpu.github.io/dmitry-fadeev-portfolio/
```

## Проверка перед релизом

Перед публикацией обязательно запустить:

```bash
npm.cmd run build
```

Для UI-изменений дополнительно проверяются desktop и mobile viewport: отсутствие горизонтального скролла, читаемость карточек, работа burger-меню, формы, модального окна диплома и корректность ссылок.
