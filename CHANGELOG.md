# Changelog

Все заметные изменения проекта фиксируются в этом файле.

Формат близок к [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Версии идут по смыслу изменений.

## [1.3.0] - 2026-08-08

### Добавлено

- Figma-inspired финальная версия главной страницы в темном минималистичном стиле.
- Новый editorial-портрет в блоке «Обо мне».
- Визуальные abstract-иллюстрации для ключевых кейсов и PM-артефактов.
- Отдельный мини-блок GitHub-проектов после артефактов.
- Компактные метрики: `5 лет`, `до 10 проектов`, `до 5 млн ₽`.

### Изменено

- Hero стал короче и спокойнее: без портрета, без второго CTA и без лишнего текста.
- Блоки «Кейсы» и «Опыт» сведены в один блок «Ключевые кейсы».
- Контакты упрощены: Email, VK и скрытая форма по кнопке «Связаться».
- Мобильный header и burger доведены до плотного, ровного вида.
- Метрики выровнены на desktop и mobile, без случайных переносов и сдвигов.
- README обновлен под финальную публичную версию.

### Удалено

- Лишняя «вода» из первого экрана и описаний.
- Дублирующие блоки и вторичные CTA.
- Telegram и GitHub-кнопка из контактного блока.
- Большая отдельная карточка для B2B-опыта, оставлена компактная поддерживающая строка.

### Проверено

- `astro-check`: 0 ошибок, 0 предупреждений, 0 подсказок.
- `astro build`: успешно.
- Browser smoke на desktop и мобильных размерах: без горизонтального overflow, наложений и недоступных кнопок.

## [1.3.0] - 2026-08-11

### Добавлено

- Figma-inspired версия портфолио с темным минимализмом, крупной типографикой и оранжевой геометрией.
- Новый editorial-портрет в блоке «Обо мне».
- Блок «Ключевые кейсы» с фокусом на WID, W3Promo и Pixel Runner.
- Визуальные карточки проектных артефактов вместо простых текстовых плиток.
- Отдельный мини-блок GitHub-проектов: Spine Flow, Pogoda Seychas и My First Site.
- Компактное B2B-подтверждение опыта ROVI Factoring Plus / Delta Leasing.

### Изменено

- Первый экран стал титульным: без портрета, без второго CTA, с короткой ролью и одной кнопкой «Посмотреть проекты».
- Header приведен к единому burger-формату на desktop и mobile.
- Блок «Обо мне» сокращен до личного сигнала, метрик и подтверждения IT-подхода.
- Блоки «Опыт» и «Кейсы» объединены в «Ключевые кейсы», чтобы убрать дубли.
- Контактный блок показывает только Email, VK и кнопку открытия формы.
- Форма связи скрыта до клика по кнопке «Оставить короткое сообщение».
- Мобильная версия доработана по iPhone SE, iPhone 12 Pro и iPhone 14 Pro Max: без горизонтального overflow и наложений.

### Удалено

- Портрет из первого экрана.
- Лишние подписи, eyebrow-метки и повторяющиеся описания.
- Второстепенные кейсы из ведущей тройки.
- Telegram и GitHub-кнопка из контактного блока.

### Проверено

- `astro-check`: 0 ошибок, 0 предупреждений, 0 подсказок.
- `astro build`: успешно.
- Browser smoke на 320, 390, 430, 768 и 1440 px: без горизонтального overflow, burger закрывается по клику вне меню, CTA ведет к кейсам, форма открывается только после клика.

## [1.2.0] - 2026-08-03

### Добавлено

- Вкладка «Мои проекты» в desktop- и mobile-header.
- Прямой PDF диплома в `public/docs`.
- Политика конфиденциальности и согласие на обработку данных.

### Изменено

- Первый экран стал лаконичнее.
- Мобильные раскрывающиеся блоки приведены к аккуратному формату.
- Контактная форма показывает уведомление только после ошибки или успешной отправки.

### Удалено

- Кнопка «Смотреть диплом» из первого экрана.
- Кнопка «Наверх».
- Лишние ссылки из карточек кейсов.
