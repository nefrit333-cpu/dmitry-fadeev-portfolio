# Changelog

Все заметные изменения проекта фиксируются в этом файле.

Формат близок к [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии идут по смыслу изменений.

## [1.1.0] - 2026-08-01

### Добавлено

- Новый премиальный темный визуальный стиль с фоном, акцентными CTA и плавным переключением темы.
- Компактный мобильный хедер с коротким брендом `ДФ`.
- Объединенный блок «Опыт и кейсы»: сначала опыт, затем практические кейсы.
- Кейс Pixel Runner в опыте и в кейсах.
- Кейс WID и ссылки на официальный сайт.
- Кейс Яндекс Практикума с дипломным контуром.
- Блок «Проектные артефакты» с отдельными папками Google Drive по направлениям.
- Страницы `privacy` и `consent` для политики конфиденциальности и согласия на обработку персональных данных.
- Согласие на обработку данных в форме связи.
- Кнопка VK с рабочей ссылкой `https://vk.ru/diman_goodcat`.

### Изменено

- Главная страница переработана под более продающую структуру: позиционирование, метрики, подход, опыт, кейсы, артефакты, диплом и контакты.
- Карточки опыта приведены к одному формату с карточками кейсов.
- Блок навыков возвращен в компактном формате без hover-эффектов.
- GitHub-блок растянут по ширине и оставлен только с публичными репозиториями.
- Контактная форма сдвинута ближе к центру на широких экранах.
- Валидация формы уточнена: имя допускает русские и английские буквы с пробелами, email должен содержать `@`, тема должна быть не короче 10 символов.
- Уведомления формы показываются только после результата: ошибка или успешная отправка.
- README и CONTRIBUTING обновлены под текущую публичную версию.

### Удалено

- Упоминания локации.
- Телефон и чувствительные данные из публичного интерфейса.
- Приватные репозитории и лишние технические блоки.
- Кнопка «Наверх».
- Дубли между блоками опыта и кейсов.

### Проверено

- `npm.cmd run build`: 0 ошибок, 0 предупреждений, 0 подсказок.
- Browser smoke для desktop и mobile: без горизонтального overflow.
- Проверены ссылки на артефакты, GitHub, VK, диплом, privacy и consent.

## [1.0.0] - 2026-07-29

### Добавлено

- Первая публичная версия Astro-сайта портфолио.
- GitHub Pages workflow для публикации.
- Базовые блоки профиля, опыта, проектов, образования и контактов.
